## 决策文档模板

每篇都用同一套骨架，保证一屏能看完：

```md
# 标题
> 状态: 生效中 / 临时妥协（计划移除） / 已废弃
> 日期: YYYY-MM 起
> 落点: home.nix 的哪一段 / 哪个文件

## 问题        一句话说清要解决什么
## 决定        最终怎么做的
## 理由        为什么，含证据（可复现的命令或日志路径）
## 代价        这个选择带来的坏处
## 复查条件    什么情况下该把它推翻
```

**"复查条件"是最容易被忽略也最重要的一条**——没有它，临时妥协会变成永久负债。
